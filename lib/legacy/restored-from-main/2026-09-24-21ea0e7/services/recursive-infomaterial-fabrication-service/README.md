# Recursive Infomaterial Fabrication Service

This conductor discovers signed provider cards, synthesizes and independently
assays the exact recursive circuit, obtains a complete shallow plate, delegates
every child observation, and assembles the admitted child receipts into one
gap-free material cover. It does not read the material locally.

Version `3.0.3` closes the published dependency graph around directory-plate
observation `2.0.5`, infomaterial observation `2.0.5`, patch cover `3.0.6`, and
hierarchical-circuit equivalence `1.0.9`. Tests resolve those installed packages
rather than deleted science-tree runtime copies.

Operational execution requires:

- signed A2A endpoints for circuit synthesis, equivalence, plate observation,
  patch observation, and patch-cover assembly;
- `WITNESS_JOURNAL_DOCUMENT_AGENT` for explicit receipt byte custody and
  category indexing; and
- `EVM_RPC_URL` plus `EVM_DEPLOYMENT_REGISTRY` for the board's admitted
  settlement-account binding.

The default suite proves conductor logic and refusal behavior. Live board and
cross-machine assays remain explicitly gated because they require those current
external endpoints; skipped tests are not deployment evidence.
